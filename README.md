# YapLab — Speech Practice

YapLab is a single-file interactive web application designed to help you practice impromptu speaking, structure your talks, and reduce your use of filler words.

## 🚀 Features

- **Practice Tab:**
  - **Topic Generator:** Practice speaking on curated topics across Design, Opinions, Storytelling, Impromptu, and Persuasion.
  - **Speech Timer:** Configurable speech length with visual progress.
  - **Filler Word Tracker:** Uses Web Speech API (speech-to-text) to track and count filler words like *um, uh, like, basically, you know*.
  - **Progression System:** Completed reps unlock harder topics.
- **Learn Tab:**
  - **Reading Backlog:** Track topics you want to learn or read about.
  - **Script Builder:** Draft structured scripts using storytelling, persuasion, or tutorial templates, complete with WPM-based duration estimation and drag-and-drop reordering.

## 🛠️ Technology Stack

- HTML5, Vanilla JavaScript, and CSS variables for theming (Light/Dark mode).
- Web Speech API for voice-to-text filler word tracking.
- LocalStorage integration for data persistence.

## 🏃 Getting Started

Simply open `index.html` in any modern web browser to start practicing!
